# 🎱 SABO Arena là gì?

## Giới thiệu

**SABO Arena** là nền tảng giải đấu Billiards trực tuyến đầu tiên tại Việt Nam, kết hợp công nghệ blockchain và gamification.

## Tính năng chính

### 🏆 Giải đấu trực tuyến
- Tổ chức giải đấu Billiards online
- Bracket system tự động
- Live scoring & tracking
- Bảng xếp hạng real-time

### 💰 SABO Token
- Token thưởng cho người chơi
- Sử dụng trong hệ sinh thái SABO
- Blockchain: Solana
- Total Supply: 1,000,000,000 SABO

### 🎮 Gamification
- Hệ thống XP & Level
- Achievement badges
- Daily check-in rewards
- Referral program

### 📱 Mobile App
- Flutter-based mobile app
- Cross-platform (iOS & Android)
- Real-time tournament updates
- Push notifications
