## 📝 Hướng Dẫn Publish

### Bước 1: Mở AI News Admin
```
https://saboarena.com/ai-news-admin
```

### Bước 2: Tạo Article

Cho mỗi bài viết:

**Title:** Copy tiêu đề từ file markdown

**Slug:** Dùng tên file (bỏ số đầu)
- Ví dụ: `huong-dan-choi-bida-cho-nguoi-moi`

**Category:** `guide`

**Language:** `vi`

**Status:** `published`

**Featured:** `true` cho bài quan trọng

**Content:** Copy toàn bộ nội dung markdown

**Meta Description:** Lấy từ cuối mỗi file

**Tags:** Lấy từ cuối mỗi file

### Bước 3: Index lên Google

Sau khi publish mỗi bài:

```bash
cd d:\0.PROJECTS\02-SABO-ECOSYSTEM\sabo-arena\website

# Index URL
node index-sabo-pages.mjs index-url https://saboarena.com/news/[slug]

# Regenerate sitemap
node generate-sitemap.mjs

# Submit sitemap
node index-sabo-pages.mjs submit-sitemap
```

## 📌 Ghi Chú

### Giọng Văn
- **Thân thiện, gần gũi** - như admin đang nói chuyện với member
- **Khiêm tốn** - không khoe khoang, tự cao
- **Chuyên nghiệp** - thông tin chính xác, có giá trị
- **Hỗ trợ** - luôn sẵn sàng giúp đỡ

### Định Dạng
- Sử dụng heading rõ ràng (H1, H2, H3)
- Có bảng so sánh khi cần
- Bullet points cho dễ đọc
- Emoji để tăng tương tác
- CTA (Call to Action) cuối bài

### Internal Links
Mỗi bài nên link đến:
- 2-3 bài viết liên quan khác
- Trang chính SABO ARENA
- App download page
